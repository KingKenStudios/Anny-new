## 20. ANNY'S MEMORY

Anny uses multi-level memory.

### Working Memory

Temporary task information.

### Session Memory

Conversation/session state.

**Redis**

### Persistent Project & Codebase Memory

Long-term understanding of projects.

**PostgreSQL + Drizzle**

### Vector Knowledge Memory

Semantic knowledge retrieval.

**Qdrant + embeddings + HNSW**

### Hybrid RAG

**BM25 + Dense Vector Search + Reciprocal Rank Fusion + Cross-Encoder Re-ranking**

This allows Anny to remember and retrieve relevant information across large projects and knowledge bases.
